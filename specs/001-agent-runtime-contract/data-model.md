# Data Model: Agent Runtime Contract (ARC)

**Date**: 2026-05-13
**Spec**: [spec.md](spec.md)

## Entities

### AgentRuntime CR (extended)

The existing `agent.kagenti.dev/v1alpha1` AgentRuntime CRD is extended with an `arc` section.

```yaml
apiVersion: agent.kagenti.dev/v1alpha1
kind: AgentRuntime
metadata:
  name: my-agent
  namespace: team1
  labels:
    kagenti.io/type: agent
spec:
  type: agent
  targetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: my-agent
  arc:                              # NEW: ARC configuration
    contractVersion: "v1alpha1"     # optional, defaults to platform version
    tracing:
      enabled: false                # default: false
    obo:
      mode: "none"                  # "none" | "token-forwarding" | "correlation-header"
```

**Field rules**:
- `spec.arc` is optional. If absent, the agent gets the base contract (identity, proxy, AGENTS.md) with defaults.
- `spec.arc.contractVersion` defaults to the platform's current version. Override is for testing/migration.
- `spec.arc.tracing.enabled` controls `OTEL_EXPORTER_OTLP_ENDPOINT` injection.
- `spec.arc.obo.mode` controls OBO delegation behavior in the sidecar and AGENTS.md content.

### ARC Contract ConfigMap

Per-agent ConfigMap generated by the controller. Contains the materialized AGENTS.md.

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: <agent>-arc-contract
  namespace: <namespace>
  labels:
    kagenti.io/type: arc-contract
    kagenti.io/agent: <agent-name>
  ownerReferences:
    - apiVersion: agent.kagenti.dev/v1alpha1
      kind: AgentRuntime
      name: <agent-name>
data:
  AGENTS.md: |
    ---
    contract_version: v1alpha1
    target_type: Deployment
    bindings:
      - identity
      - model-access
      - trace-collector
    arc_root: /arc
    ---
    # Agent Runtime Contract
    
    ## Platform-Provided Environment Variables
    ...
```

**Lifecycle**: Created when AgentRuntime CR is created. Updated when platform config changes (MCPServerRegistration, tracing, contract version). Deleted when AgentRuntime CR is deleted (ownerReference cascade).

### ARC MCP ConfigMap

Per-agent (or per-namespace) ConfigMap with MCP server discovery data.

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: <agent>-arc-mcp
  namespace: <namespace>
  labels:
    kagenti.io/type: arc-mcp
    kagenti.io/agent: <agent-name>
  ownerReferences:
    - apiVersion: agent.kagenti.dev/v1alpha1
      kind: AgentRuntime
      name: <agent-name>
data:
  servers.json: |
    {
      "mcpServers": {
        "gateway": {
          "url": "http://mcp-gateway-broker.mcp-system:8080/mcp"
        },
        "weather-tool": {
          "url": "http://weather-tool-service.team1:8080/mcp"
        }
      }
    }
```

**Lifecycle**: Regenerated when MCP tool Deployments with `kagenti.io/protocol=mcp` label are added/removed in the agent's namespace or when the MCP Gateway URL changes.

### AGENTS.md Structure

Conforms to the [AGENTS.md open standard](https://agents.md/). YAML frontmatter with ARC extension fields, Markdown body.

**Frontmatter fields** (ARC extensions, ignored by standard tooling):

| Field | Type | Description |
|-------|------|-------------|
| `contract_version` | string | ARC version (e.g., `v1alpha1`) |
| `target_type` | string | Deployment, StatefulSet, or Sandbox |
| `bindings` | list | Available ServiceBinding categories |
| `arc_root` | string | Root path for ARC content (always `/arc`) |
| `obo_mode` | string | OBO delegation mode (none, token-forwarding, correlation-header) |
| `tracing_enabled` | boolean | Whether OTEL tracing is configured |

**Body sections**:

1. Platform-Provided Environment Variables (table: name, value, description)
2. Mount Paths (table: path, contents, provisioned by)
3. Auth Behavior (inbound, outbound, agent-to-agent, user-to-agent)
4. Agent Requirements (A2A card, health probes, container port)
5. MCP Server Access (reference to `/arc/mcp/servers.json`)
6. Skills (reference to `/arc/skills/`)
7. Target-Specific Notes (varies by target type)

### Environment Variables Injected

| Variable | Source | Injected by | Condition |
|----------|--------|-------------|-----------|
| `ARC_CONTRACT_VERSION` | Platform config | Webhook | Always |
| `ARC_AGENT_ID` | SPIFFE ID | Webhook | Always |
| `ARC_NAMESPACE` | Pod namespace | Webhook | Always |
| `ARC_MCP_CONFIG` | `/arc/mcp/servers.json` | Webhook | Always |
| `ARC_SKILLS_DIR` | `/arc/skills/` | Webhook | Always |
| `HTTP_PROXY` / `HTTPS_PROXY` | Sidecar endpoint | Webhook | Deployment/StatefulSet targets |
| `SPIFFE_ENDPOINT_SOCKET` | SPIRE CSI | Webhook | Always |
| `SERVICE_BINDING_ROOT` | `/bindings` | Webhook | Always |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | OTEL collector | Webhook | `spec.arc.tracing.enabled: true` |

### Volume Mounts Injected

| Mount Path | Source | Type | Condition |
|------------|--------|------|-----------|
| `/arc/AGENTS.md` | `<agent>-arc-contract` ConfigMap | subPath mount | Always |
| `/arc/mcp/servers.json` | `<agent>-arc-mcp` ConfigMap | subPath mount | Always |
| `/arc/skills/` | emptyDir (populated by init container) | volume mount | When skills configured |
| `$SERVICE_BINDING_ROOT/identity/` | SPIRE CSI driver | CSI volume | Always |

## Relationships

```
AgentRuntime CR (1) ──owns──▶ (1) ARC Contract ConfigMap
AgentRuntime CR (1) ──owns──▶ (1) ARC MCP ConfigMap
AgentRuntime CR (1) ──references──▶ (1) Deployment/StatefulSet
Deployment (1) ──has──▶ (N) Pods with /arc/ mounts
Controller ──watches──▶ MCP Tool Deployments (label: kagenti.io/protocol=mcp)
Controller ──watches──▶ AgentRuntime CRs
Controller ──generates──▶ ARC Contract ConfigMap + ARC MCP ConfigMap
Webhook ──mutates──▶ Pods matching kagenti.io/type=agent
```
